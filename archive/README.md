# Archived project artifacts

This directory preserves old patch payloads and setup notes for reference only.
**Do not apply these patches to the current repository.** They were created
against older versions of the solver and can revert bug fixes or research work.

- `patches/`: legacy Git patches used during initial development and strategy testing.
- `legacy/`: old correction-package directions, a misfiled stale test source,
  and historical benchmark CSV data without modern run metadata.

Current source code lives at the repository root, tests in `tests/`, and
run/benchmark instructions in [the README](../README.md).
